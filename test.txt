File encryption tool written in C++23 using [libsodium](https://github.com/jedisct1/libsodium).

The project is split into two main parts:

* `core` — cryptographic logic and encrypted file format
* `app` — command-line application used to encrypt and decrypt files

## Features

* File encryption and decryption
* Password-based key generation
* Argon2id password hashing through libsodium
* Random salt generation
* Random nonce generation
* Encrypted file format with stored salt and nonce
* C++23
* CMake build system

## How It Works

The application uses a password to derive an encryption key.

During encryption:

1. A random salt is generated.
2. A key is derived from the password using Argon2id.
3. A random nonce is generated.
4. The file is encrypted using `crypto_secretbox_easy`.
5. The encrypted file is saved with the `.encrypted` extension.

The encrypted file contains:

* Salt
* Nonce
* Encrypted file data

During decryption, the salt stored in the encrypted file is used to derive the same key from the provided password. The encrypted data is then decrypted and restored to the original file.

## Build

### 1. Clone the repository

```bash
git clone <repository-url>
cd FileEncryptor
```

### 2. Install Dependencies

Make sure `libsodium` and `pkg-config` are installed and available on your system.

### 3. Build the Project

```bash
cmake -B build
cmake --build build
```

The project uses CMake to build both the `core` library and the `app` executable.

## Usage

The current application expects a file path as a command-line argument:

```bash
App_1 <path-to-file>
```

The application currently provides the following options:

```text
1. Encrypt File
2. Decrypt File
3. Exit
```

Encrypted files are saved with the `.encrypted` extension.

> The CLI interface is still under development and will be improved in future versions.

    ## Core Library

    The `core` module contains the main cryptographic functionality of the project.

    It is responsible for:

    * Encryption
    * Decryption
    * Password-based key generation
    * File format handling
    * Saving encrypted files
    * Loading encrypted files

    The cryptographic operations are implemented using libsodium primitives.

## Security

This project is currently under development.

Although the project uses established cryptographic primitives provided by libsodium, it has **not been professionally audited**.

Do not rely on this project for protecting sensitive or critical data.

## Usage

Run the application with the path to the file you want to encrypt or decrypt:

```text
App_1 [file_path]
```

After starting the application, select an operation and provide the password:

```text
1 <password>    # Encrypt file
2 <password>    # Decrypt file
3               # Exit
```

For example:

```text
App_1 example.txt

1 mypassword
```

To decrypt the encrypted file:

```text
App_1 example.txt.encrypted

2 mypassword
```

To exit the application:

```text
3
```
